# Training-Planner

Галимова Рузалина 

1. Общее описание
Training Planner — это графическое приложение для планирования и учёта спортивных тренировок, написанное на языке Python с использованием встроенной библиотеки tkinter. Программа позволяет пользователю добавлять тренировки, фильтровать их по различным критериям, сохранять данные в формате JSON и загружать обратно.
Приложение разработано в рамках учебной практики по программированию. Основная цель — закрепить навыки работы с графическим интерфейсом, обработкой данных, файловым вводом-выводом и валидацией пользовательского ввода.
2. Функциональные возможности
2.1 Добавление тренировок
Пользователь заполняет три поля:
Дата — в формате ДД.ММ.ГГГГ (например, 25.05.2026)
Тип тренировки — выбирается из готового списка (бег, плавание, йога и др.)
Длительность — целое положительное число в минутах
При нажатии кнопки «Добавить тренировку» данные проверяются на корректность и, если всё верно, добавляются в таблицу.
2.2 Фильтрация данных
Реализована фильтрация по двум параметрам:
По типу тренировки — показываются только тренировки выбранного вида
По дате — отображаются тренировки за конкретный день
Также есть кнопка «Сбросить фильтр» для возврата к полному списку.
2.3 Работа с JSON
Сохранение — данные экспортируются в файл .json через стандартный диалог сохранения
Загрузка — ранее сохранённые тренировки импортируются обратно в приложение
При загрузке происходит проверка структуры файла на корректность.
2.4 Дополнительные функции
Удаление записи — выделить строку в таблице и нажать кнопку удаления
Редактирование — двойной клик по строке переносит данные в поля ввода
Статистика — внизу окна отображается общее количество тренировок и суммарная длительность
3. Примеры использования
Пример 1: Добавление новой тренировки
Шаги:
Запустить программу (python training_planner.py)
В поле «Дата» ввести: 26.05.2026
В выпадающем списке «Тип тренировки» выбрать: Бег
В поле «Длительность» ввести: 45
Нажать кнопку «Добавить тренировку»
Ожидаемый результат: В таблице появляется новая строка: 26.05.2026 | Бег | 45. В статистике обновляется счётчик.
Пример 2: Проверка валидации даты
Шаги:
В поле «Дата» ввести некорректное значение: 32.13.2026
Заполнить остальные поля корректно
Нажать «Добавить тренировку»
Ожидаемый результат: Появляется окно ошибки с текстом: «Неверный формат даты! Используйте ДД.ММ.ГГГГ». Запись в таблицу не добавляется.
Пример 3: Проверка валидации длительности
Шаги:
В поле «Длительность» ввести: -10 (или abc)
Заполнить остальные поля корректно
Нажать «Добавить тренировку»
Ожидаемый результат: Появляется окно ошибки: «Длительность должна быть положительным целым числом!»
Пример 4: Фильтрация по типу тренировки
Предусловие: В таблице есть несколько тренировок разных типов (Бег, Йога, Плавание).
Шаги:
В блоке «Фильтрация» в поле «Тип» выбрать: Бег
Поле «Дата» оставить пустым
Нажать «Применить фильтр»
Ожидаемый результат: В таблице отображаются только тренировки типа «Бег». Статистика пересчитывается только для отфильтрованных записей.
Пример 5: Фильтрация по дате
Шаги:
В поле фильтра «Дата» ввести: 26.05.2026
В поле «Тип» оставить «Все»
Нажать «Применить фильтр»
Ожидаемый результат: Показаны только тренировки за 26 мая 2026 года.
